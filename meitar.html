פרויקט ללקוח

מיתר — בית חינוך ברוח דיאלוגית

אתר מידע והרשמה שמציג את בית החינוך, מוביל הורים למילוי פרטים, מאפשר יצירת קשר ושומר את הפניות בצורה מסודרת ב-Google Sheets.

HTML CSS JavaScript Google Apps Script Google Sheets

תיאור הפרויקט

הפרויקט נבנה כאתר פשוט וברור לבית החינוך מיתר. המטרה הייתה ליצור דף שמסביר במהירות מה המקום מציע, נותן להורים דרך להשאיר פרטים, ומרכז את הפניות בצורה שקל להמשיך ממנה.

מבחינה טכנית זה דומה לדף ההרשמה של סדנאות הקיץ: אתר סטטי ב-HTML, CSS ו-JavaScript, עם חיבור ל-Google Apps Script ששומר את הנתונים ל-Google Sheets. ההבדל הוא שכאן אין תשלום, אלא זרימה של מידע, יצירת קשר והרשמה ראשונית.

דף נחיתה ברור

מסר מרכזי, רקע ויזואלי, כפתור למילוי פרטים ופרטי קשר זמינים.

טופס פרטים

איסוף פרטי מתעניינים בצורה פשוטה, בלי להעמיס על המשתמש בשלב הראשון.

שמירה לגיליון

חיבור ל-Google Sheets דרך Google Apps Script כדי לרכז פניות במקום אחד.
